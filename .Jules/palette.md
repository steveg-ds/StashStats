## 2025-05-15 - Contextual Modal Titles
**Learning:** In a list-heavy interface where users can trigger modals for multiple items (like stash entries), generic modal titles like "Edit Stash Entry" can lead to user disorientation if they lose track of which item they clicked. Providing the item's name (e.g., "Edit: [Yarn Name]") in the modal header significantly improves user confidence and orientation.
**Action:** Always aim to include specific item identifiers in modal headers when they are triggered from a list or grid of similar items.
